# AI Guardian - Next-Gen Multi-Modal AI Platform for Women's Safety

AI Guardian is an advanced multi-modal artificial intelligence Women's Safety platform combining real-time spatial computer vision, acoustic distress voice detection, predictive risk analysis, and automated emergency response dispatch.

---

## 🌟 Key Features

- **🎙️ Acoustic Voice Intelligence**: Real-time Web Audio API waveform visualizer and distress keyword spotter (`"Help"`, `"Emergency"`, `"Save me"`).
- **👁️ Spatial Computer Vision**: Live WebCam feed integration with real-time glowing bounding box detection overlays (`Violence Detected`, `Weapon Detected`, `Fall Detected`, `Unknown Person`).
- **🗺️ Interactive Spatial Vector Map**: Real-time dark-mode navigation map featuring user GPS location, animated safe route vectors, police stations, medical centers, and risk zone heatmaps.
- **⚡ Instant Emergency SOS**: Pulsing warning trigger with 3-second countdown modal, automated 911 dispatch, and stealth recording broadcast.
- **🤖 Conversational AI Assistant**: Floating AI Guardian assistant with step-by-step AI thought reasoning visualization.
- **📈 Telemetry & Analytics**: Real-time safety score gauges, response time benchmarks, and threat trend charts.

## 🚀 Quick Start & Installation

### Option 1: Direct Browser Access
Open `index.html` directly in any modern browser.

### Option 2: Local HTTP Server (PowerShell)
Run the included PowerShell server script:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Navigate to `http://localhost:8080` in your web browser.
